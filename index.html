I am an Associate Professor of Computer Science at Renmin University of China (RUC), where I lead the Data Systems Group. My research focuses on high-performance data systems for AI and big data analytics, including cloud-native databases, data lakehouses, AI-native storage systems, and hardware-aware data processing.

欢迎有意攻读硕士或博士研究生等同学和我联系，也欢迎RUC或其他学校同学加入课题组的研究工作和项目实习！

Research Interests

Cloud-Native Data Systems

Cloud-native databases, data warehouses, and data lakehouses with disaggregated storage and compute architectures.

AI-Native (Multimodal) Data Systems

Novel storage systems designed for AI workloads, enabling efficient data access for machine learning and analytics.

Hardware-Aware Data Processing

Data systems optimized for modern hardware including new storage devices, accelerators, and heterogeneous architectures.

Automated Database Diagnosis and Optimization

Elastic and cost-efficient query processing using serverless cloud functions and adaptive resource allocation.

Open Source Projects

Pixels — Cloud Data Lakehouse Engine

An efficient storage and compute engine for both on-prem and cloud-native data analytics. Pixels features an optimized columnar storage format, serverless query acceleration using cloud functions, natural-language-aided data analytics, and flexible pricing with service-level guarantees.

900+ Stars 150+ Forks Since 2017

Impact: Key columnar storage techniques from Pixels are incorporated into China's National Standard GB/T 41818-2022 on analytical data storage. Query execution technologies and code have been adopted by major cloud vendors for database product prototyping.
